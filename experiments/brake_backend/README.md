# 单车制动标定：独立 CARLA 与 CARLA–SUMO 的速度差出现在哪一帧？

复算固定输入标定的 72 次既有运行。Town04 同一生成点、Tesla Model 3、50 ms 采样；设定初速 6、12、18 m/s，制动强度 0.4、0.7、1.0，物理子步 10、3.125 ms。每个组合在两种后端各跑两轮，共 36 对。1.00 s 提交固定制动请求，日志先记录状态再下发该帧指令。两次重复按相同轮次配对。

| 工况 | 最早速度差超过 0.000001 m/s | 请求前最大绝对差 | 从请求至 16 s 的最大绝对差 |
|---|---:|---:|---:|
| 6 m/s，制动 0.4，子步 10 ms，首轮 | 0.00 s | 5.625951 m/s | 0.247053 m/s |
| 6 m/s，制动 0.7，子步 3.125 ms，首轮 | 0.00 s | 5.788625 m/s | 0.021183 m/s |
| 其余 34 对 | 无超阈值帧 | ≤ 0.000001 m/s | ≤ 0.000001 m/s |

两处最大差均出现在记录首帧。相同配置的第二轮未再超过阈值。用完整窗口的最大差值评价制动性能，会把发出制动请求之前已有的速度差算进去。日志能确定差异出现的时刻，其具体生成机制仍需针对起步初始化单独做对照。结论限于该批次的仿真车速。

```bash
python experiments/brake_backend/compare.py docs/brake_calibration_traces.zip pairs.csv
```
